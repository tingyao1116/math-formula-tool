# 數學顯示規則（無限練習）

本文件作為本專案新增/修改題型時的統一格式規範。  
原則：**先正確，再最簡，再易讀**。

## 1) 係數 1 的省略
- `1x` 一律顯示為 `x`。
- `1x^2` 一律顯示為 `x^2`。
- `-1x` 顯示為 `-x`，`-1x^2` 顯示為 `-x^2`。

## 2) 負號與減負數寫法
- 不允許出現連續減號：`x--y`。
- 必須寫成：`x-(-y)`。
- 同理，其他類似位置都遵守此規則（如常數項、代入後算式）。

## 3) 分數一律最簡
- 分數要約成最簡分數（約分到互質）。
- 若可化為整數，直接顯示整數。
- 例：`6/8 -> 3/4`，`10/5 -> 2`。

## 4) 比例一律最簡整數比
- 比例 `a:b` 需先同乘/同除去掉小數與分母，再約成互質整數比。
- 例：`0.5:1.2 -> 5:12`，`6:8 -> 3:4`。

## 5) 根式一律最簡根式
- `\sqrt{n}` 若可提出平方因數，必須提出。
- 例：`\sqrt{48} -> 4\sqrt{3}`，`\sqrt{220} -> 2\sqrt{55}`。
- 係數若為 1，省略成 `\sqrt{m}`。

## 6) 分母有根號時要有理化
- 最終答案若分母含根號，需完成有理化分母。
- 單根號分母與雙項分母（共軛）都適用。

## 7) 答案呈現層次
- `簡答`：優先給最終最簡結果。
- `過程`：若題型需要，過程可保留中間步驟，但最後一行必須符合本規範（最簡分數、最簡根式、已有理化）。

## 8) 題幹與解答分工
- 題幹只放原題，不放技巧提示（例如換元 `t=...`）。
- 技巧（換元、配方、判別式等）放在答案過程中。

---

實作建議（程式端）：
- 優先用共用格式化函式處理：
  - `formatCoeffTerm(coeff, variable, power)`
  - `formatSubtraction(left, right)`（避免 `x--y`）
  - `reduceFraction()`
  - `formatFraction(n, d)`
  - `simplifyRadical()` / `formatRadical()`
  - `rationalizeDenominator()`
  - `formatRatio(a, b)`
- 新題型上線前，至少抽查：
  - 係數 1、省略是否正確
  - 是否有 `--`
  - 分數/比例/根式是否最簡

## 9) 目前共用 formatter 位置
