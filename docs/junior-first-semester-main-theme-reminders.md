# 國一上主題整理提醒

這份提醒只記國一上目前已經踩過、之後很容易再踩一次的點。做 `j1-*` 時先看這裡，再開始動資料。

## 固定模式

1. 章節代碼是第一層，不改。
2. 章節底下先補穩定的 `主題` 層。
3. 每個主題先完成 `可修改版 / 原稿版`。
4. 舊主題與舊分支再往下掛，不要和主題層並列。
5. 章節大綱第三欄優先用主題整理裡的重點，不要直接拿舊分支名硬拼。
6. 主題標題不要帶 `主題1：` 這種前綴。

## 來源檔優先順序

1. `data/junior-source/j1-readable-paged.pdf`
2. `國一上_易讀版分頁版.docx`
3. 舊 `formula-db.json` 只拿來判斷既有分支，不拿來決定新主題。

## PDF 命名

- 命名規則：`{chapter-code}-topic-{index}-{slug}.pdf`
- 存放位置：`data/main-theme-overviews`
- 國一上對照表：`data/main-theme-overviews/junior-first-semester-topic-pdfs.json`

## 國中額外注意

- 國中主題不預設「一頁一主題」。
- 先看 PDF 連續頁的標題是否相同，再決定：
  - `pageStart`
  - `pageEnd`
- 原稿版可以是一個跨多頁的 PDF，只要它仍然是同一主題。

## 可修改版注意

- 中文一律保留 UTF-8。
- 分數、根號、絕對值、不等式一律改成明確 TeX：
  - `√2` -> `\(\sqrt{2}\)`
  - `(a+b)/2` -> `\(\frac{a+b}{2}\)`
  - `|x|<5` -> `\(|x|<5\)`
- GUI 和主頁現在都只認明確 TeX，不要期待自動轉公式。
