# 國一下主題整理提醒

這份提醒文件是給 `j2-*` 章節使用，目的不是批次亂套，而是固定住前面高中與國一上已經驗證過的流程。

## 固定流程

1. 先看 Word / PDF 的主題，不先看舊 `formula-db.json` 決定主題。
2. 主題先做成：
   - 可修改版
   - 原稿版 PDF
3. 主題掛到章節 root 下面。
4. 舊 root 與舊分支再往主題下面附掛。
5. 最後再反推章節大綱。

## 命名與顯示

- 主題名稱不要帶 `主題1：` 這類前綴。
- 章節大綱第一欄直接用主題名稱。
- 章節大綱第二欄統一先寫 `主題`。
- 章節大綱第三欄優先取主題整理表的重點，不直接抄舊分支名稱。

## TeX 與文字安全

- 中文維持 UTF-8，不要改成跳脫字元。
- 數學式要改成主頁能直接顯示的 TeX。
- 常見改寫：
  - `√a` -> `\\(\\sqrt{a}\\)`
  - `a/b` -> `\\(\\frac{a}{b}\\)`
  - `(x,y)` -> `\\((x,y)\\)`
  - `x=...` -> `\\(x=\\cdots\\)`
  - `x+y=5` -> `\\(x+y=5\\)`

## j2-1-1 ~ j2-1-3 特別注意

- `j2-1-1` 是 `二元一次方程式`：
  - 先放列式、二元一次式/方程式、同類項運算、解與限制條件。
- `j2-1-2` 是 `二元一次聯立方程式`：
  - 先放聯立的意義、解的型態、代入/加減消去。
- `j2-1-3` 是 `二元一次方程式應用問題`：
  - 先放應用題列式、建模流程、答案檢查。

  - `應用題列式`
  壓在同一頁。

  - `j2-1-2` 保留解聯立主線
  - `j2-1-3` 獨立保留應用題建模主線
- 若原稿版需要共用同一頁 PDF，是可接受的；之後若有更乾淨的切頁版，再替換即可。

## j2-2-1 ~ j2-2-2 特別注意

- `j2-2-1` 是 `座標概念`：
  - 先放數線、平面座標、象限、到軸距離、中點與座標移動。
- `j2-2-2` 是 `二元一次方程式圖形`：
  - 先放方程式的解、方程式圖形、兩直線與聯立圖解。
- `二元一次方程式的解` 雖然還帶有代數味道，但來源主軸已經放在圖形單元，這裡跟著 Word 放到 `j2-2-2`，不要拆回 `j2-1-1`。
- 若看到舊分支像：
  - `直角坐標上的直線方程式`
  - `斜率公式`
  - `斜截式`
  這些都先掛到 `j2-2-2 / 二元一次方程式的圖形` 主題下面，不要混進 `j2-2-1`。
- `三點求面積` 比較像座標應用，先掛到 `j2-2-1 / 中點座標與座標應用` 下面。

## j2-3-1 ~ j2-3-2 特別注意

- `j2-3-1` 是 `比例式`：
  - 先放 `比與比值`
  - 再放 `相等的比與比的化簡`
  - 再放 `比例式與求未知數`
  - 最後放 `比的應用：分配、合併與速度`
- `j2-3-2` 是 `正比反比`：
  - 只放 `正比`
  - `反比`
  - `正比與反比的綜合判斷`
- 來源 PDF 第 `17~23` 頁剛好就是這七個主題，這一章不要再回頭拿舊 root 的名稱決定主題。
- `j2-3-1-ratio-main` 雖然叫 `比與比值核心觀念`，但它底下混了：
  - `比例式與性質`
  - `按比分配與總份數法`
  所以附掛時一定要把這兩支拆去 `比例式與求未知數`、`比的應用`，不要整包留在第一個主題。
- `ratio-proportion` 這棵舊 root 也比較雜：
  - `放大縮小與約分擴分` 比較適合掛 `相等的比與比的化簡`
  - `內內 = 外外`、`比例常數 r` 掛 `比例式與求未知數`
  - `比例分配`、`成本/售價`、`打折`、`距離時間速度`、`濃度` 掛 `比的應用`
- `j2-3-2-direct-inverse-main` 也是跨主題舊 root：
  - `正比例關係式`、`正比圖形` 掛 `正比`
  - `反比例關係式`、`反比圖形判讀` 掛 `反比`
  - `正反比應用題`、`正比反比綜合判斷` 掛 `正比與反比的綜合判斷`
