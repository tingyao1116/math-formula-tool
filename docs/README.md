## 歷史文件去哪裡看

已退役、已過期、只保留備查的文件，不再放在 `docs/` 的正式閱讀路線裡。

請改看：

- `docs/history/`
- `archive/transitional/`

其中：

- `docs/history/` 放歷史文件本體
- `archive/transitional/` 放整理報告、盤點紀錄、過渡說明

## 判斷原則

如果你不確定一份文件是不是現況，先看這三件事：

1. 它有沒有被這份 `docs/README.md` 列為正式文件
2. 它描述的是不是現在仍存在的檔案與流程
3. 它是不是 handoff、reminder、dated snapshot、migration plan

只要比較像第 3 類，就先不要把它當正式規則。
