# UTF-8 / TeX 安全提示詞

```text
請只做資料整理與格式轉換，不要改寫原文，不要摘要，不要自行換句話說。

所有中文內容必須保留原稿用字，禁止猜字、補字、簡繁轉換錯誤、或用模糊字替代。
如果遇到任何編碼不明、無法解碼、或可能產生亂碼的來源，請直接停止並回報，不要使用 errors="replace"，不要把無法辨識的字寫成 U+FFFD replacement character。

所有文字檔與 JSON 一律使用 UTF-8 讀寫，JSON 請使用 ensure_ascii=False。
所有外部命令輸出必須以 UTF-8 嚴格解碼；如果不是 UTF-8，請報錯停止，不要自動替換。

請保留原文句子，不要自行重寫內容，不要加入工作筆記，不要加入你的摘要或心得。

數學公式與英文字母只要出現在內文中，都請用 TeX 的句內公式格式 `$...$` 包起來，例如 `$x$`、`$a_1$`、`$(x_0,y_0)$`、`$ax+by=c$`。
只有非常重要、需要獨立置中的公式，才使用 `$$...$$`。

請輸出成可以直接顯示在網站上的正式內容，不要寫成備忘錄，不要使用「主題1：」或「重點1：」這種字樣。
```
