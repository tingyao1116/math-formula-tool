# 第二冊主題整理提醒

這份文件只記第二冊後續章節要反覆檢查的事，避免又走回第一輪做錯的方向。

## 固定順序

1. 先確認章節代碼與主題歸屬。
2. 先建立主題層，不要先急著補分支。
3. 每個主題先補 `可修改版`。
4. 每個主題再補 `原稿版 PDF`。
5. 章節大綱最後再由主題重點反推。
6. 分支要等主題穩定後再往下掛。

## 主題命名

- 主題標題不要保留 `主題1：`、`主題2：` 這種前綴。
- 主題頁與章節大綱都只顯示乾淨主題名。
- 舊資料若要保留，可作為主題下的分支，不要再和主題並列。

## 可修改版

- 來源以 Word 匯出的 Markdown / 文字內容為主，不要直接抄 PDF 擷取文字。
- 數學式要明確寫成前端可渲染的格式。
- 不要依賴 GUI 自動判斷數學式；資料本身就要寫正確。
- 常見轉換：
  - `√ab` 改成 `\(\sqrt{ab}\)`
  - `a/b` 改成 `\(\frac{a}{b}\)`，前提是它真的是公式不是普通敘述
  - `a_n`、`S_n`、`P(k)` 這種符號要包在 `\(...\)`
  - `\Sigma`、不等號、箭號、冪次、根號都要用明確 TeX
- 中文文字要維持 UTF-8，不要用會把內容轉成亂碼的流程。

## 原稿版 PDF

- 原稿版的來源是「每個主題一頁」的分頁 PDF。
- 命名固定：
  - `{chapter-code}-topic-{index}-{slug}.pdf`
- 放置位置固定：
  - `data/main-theme-overviews`
- 新章節開始前，先確認：
  - PDF 的頁數對應主題沒有錯
  - 檔名和主題資料庫中的 `src` 一致

## 章節大綱

- 章節大綱的主題列，直接來自新的主題層。
- 第三欄「下一層 / 提醒」先取主題整理表中的重點，不要先硬抓舊分支名稱。
- 不要出現 `主要主題1：` 這種前綴。
- `先看` 這種多餘語氣不要放進第三欄。

## 分支附掛

- 先判斷舊分支真正屬於哪個章節，再決定 parent。
- 若舊資料章節碼掛錯，要先修正章節碼，再掛到正確主題下。
- 主題底下如果需要一層穩定承接舊資料，可以保留一個同名主題節點，但不要讓它在主頁上形成重複主卡。

## 章節歸屬先驗證

- 後面章節開始前，先做「主題 -> 章節」對照，不可以一邊做一邊猜。
- 只要某個舊分支同時像兩個章節，都要先停下來判斷它真正的教學落點，再決定掛哪一章。
- 判斷順序固定：
  1. 先看 Word / 分頁 PDF 的單元與主題標題。
  2. 再看 `chapter-code-db.json` 的章節名稱與 section。
  3. 最後才看現有 `formula-db.json` 裡舊分支原本掛在哪裡。
- 不可以因為舊分支現在掛在某章，就直接當成它一定屬於那章。
- 一個主題若主要重點明顯屬於 A 章，只是順便用到 B 章工具，仍然要掛在 A 章，不要因為用到別章技巧就拆錯。

## s2-2-1 到 s2-2-4 對照

- `s2-2-1`
  - section：`邏輯、集合與計數原理`
  - 先收：命題、真值表、條件敘述、集合運算、文氏圖、基本計數原理、容斥
- `s2-2-2`
  - section：`排列組合`
  - 先收：階乘、排列、組合、重複排列、重複組合、插空、環狀排列、分組分堆、錯排
- `s2-2-3`
  - section：`二項式定理`
  - 先收：二項展開、指定項、係數性質、中央項、加權和、常見組合恆等式
- `s2-2-4`
  - section：`古典機率`
  - 先收：樣本空間、事件、機率基本性質、補事件、加法乘法公式、等可能模型、期望值

## s2-2 附掛原則

- `s2-2-1` 和 `s2-2-2` 很容易混在一起：
  - 如果重點是在「怎麼判斷命題、集合、文氏圖、加法乘法原理、容斥」，放 `s2-2-1`
  - 如果重點是在「排法、選法、相鄰限制、重複元素、分組模型」，放 `s2-2-2`
- `s2-2-2` 和 `s2-2-4` 也容易混：
  - 如果是在算排列組合本身，放 `s2-2-2`
  - 如果排列組合只是拿來算機率分子分母，主題應掛 `s2-2-4`
- `s2-2-3` 不要被 `組合` 字樣騙走：
  - 只要核心是在二項展開、指定項、係數、恆等式，就屬於 `s2-2-3`
  - 即使中間用了組合數，也不要回掛 `s2-2-2`
- `s2-2-4` 若題目主體在事件運算、補事件、至少一個、期望值，就掛機率，不要因為用了計數模板就回掛排列組合。

## 完成前檢查

1. 主頁章節模式能先看到主題。
2. 每個主題頁都有 `可修改版 / 原稿版`。
3. `可修改版` 的數學式在主頁和 GUI 預覽都一致。
4. `原稿版` 打開的是正確的一頁 PDF。
5. 章節大綱的第三欄已改成主題重點，不是舊分支清單。
