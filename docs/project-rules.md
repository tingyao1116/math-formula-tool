# 專案暫訂規則

這份文件是目前「數學公式使用工具」的共同規格。
之後新增資料、調整章節、改顯示方式，原則上都先以這份為準；若規則變更，再同步更新此檔。

## 1. 核心方向

- 以 `章節` 為主軸整理內容。
- 以 `章節 -> 主題 -> 重點` 的方式建立結構。
- 能放正式章節的內容，優先放正式章節。
- `補充` 只保留真正屬於：
  - 聰明方法
  - 轉換想法
  - 延伸技巧
  - 題型整理

## 2. 章節的主角規則

這條規則非常重要，後續新增資料都照這個模式處理：

- **每個章節都會有最重要的一個主角（整個章節的靈魂）。**
- 其他內容分成：
  - `重要配角`：常考特殊題型、核心技巧、常用進階法
  - `配角`：小技巧、延伸方法、其他表示法、進階方法
  - `教學補充`：幫助理解的觀念、設未知數感覺、轉念方法

實作方式：

- `章節 -> 主題 -> 重點`
- 一個章節先有主題，主題裡再放重點。
- `角色` 是拿來分類主題或重點的，不是內容本身。
- 角色文字不要直接寫進公式、例題、說明裡。
- 主題或重點可設定 `chapterRole`
  - `主角`
  - `重要配角`
  - `配角`
  - `教學補充`
- 一個章節先明確指出主角，再把其他主題或重點收成分支。
- 後面各章儘量沿用這個模式。

## 3. 排序規則

- 一般顯示預設用 `課綱順序`
- 只有在修稿或檢查最近改動時，才切 `修改時間`
- 課綱順序固定依：
  - 學層
  - 年級
  - 學期
  - 章碼
  - 章節順序

## 5. 主題 / 分支規則

- 一個章節可以有多個主題，但應先明確指出主角。
- 一個主題底下可有多個分支。
- 如果只是：
  - 小技巧
  - 特例
  - 特殊題型
  - 教學補充
  就優先收進分支。

## 6. 相同概念跨年級規則

- 如果國中已出現、高中只是再次使用：
  - 原則上只保留一次
  - 放在最早出現的年級
  - 後面用 `再次出現` 標示
- 如果高中真的有明顯延伸，再另外建立分支。

## 7. 章節大綱規則

- 章節大綱可同時有：
  - `可修改版`
  - `原稿版`
- 若可修改版不夠像原稿，可只保留原稿版。
- 章節大綱 PDF 統一放在：
  - `C:\codex資料夾\數學公式使用工具\exports\chapter-overviews`
- 命名優先用章碼。

## 8. 架構檢視規則

- `structure-view.html` 直接讀網站資料。
- 架構檢視必須依年級 / 章碼排序，不依修改時間。
- 管理頁只保留「開啟架構檢視頁」入口，不把整份架構直接塞進編輯頁。

## 9. 數學顯示規則

- 公式區優先用 TeX / KaTeX 顯示。
- 公式區儘量只放數學式，不把長中文敘述混在同一行。
- 中文說明移到：
  - `usage`
  - `examples`
  - `tips`
  - `notes`
  - `mistakes`

## 10. 新增資料工作方式

- 先判斷要掛哪個正式章節。
- 能放正式章節的，不優先丟補充。
- 先決定：
  - 這章的主角是誰
  - 哪些是重要配角
  - 哪些是配角
  - 哪些是教學補充
- 再補：
  - 主題內容
  - 分支內容
  - 無限練習
  - 章節大綱（如需要）
