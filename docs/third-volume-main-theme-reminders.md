# 第三冊主題整理提醒

這份提醒只記第三冊目前已經踩過、之後很容易再踩一次的點。做 `s3-*` 時先看這裡，再開始動資料。

## 固定模式

1. 章節代碼是第一層，不改。
2. 章節底下先補穩定的 `主題` 層。
3. 每個主題先完成 `可修改版 / 原稿版`。
4. 舊主題與舊分支再往下掛，不要和主題層並列。
5. 章節大綱第三欄優先用主題整理裡的重點，不要直接拿舊分支名硬拼。
6. 主題標題不要帶 `主題1：` 這種前綴。

## 來源檔優先順序

1. `exports/s3-source/s3-readable-paged.pdf`
2. `高二上數A全重點_整理/raw_sections_final/*.md`
3. `exports/s3-source/s3-outline.txt`
4. 舊 `formula-db.json` 只拿來判斷既有分支，不拿來決定新主題。

## PDF 命名

- 命名規則：`{chapter-code}-topic-{index}-{slug}.pdf`
- 存放位置：`exports/main-theme-overviews`
- 第三冊對照表：`exports/main-theme-overviews/third-volume-topic-pdfs.json`

## 可修改版注意

- 中文一律保留 UTF-8，不要讓來源亂碼直接進資料庫。
- 平方根、分數、上下標統一改成前端可吃的 TeX：
  - `√ab` -> `\(\sqrt{ab}\)`
  - `a/b` -> `\(\frac{a}{b}\)`
  - `f^-1(x)` -> `\(f^{-1}(x)\)`
  - `log_a b` -> `\(\log_a b\)`
- 不要假設主頁會自動幫忙轉數學式；GUI 和主頁現在都只認明確 TeX。
