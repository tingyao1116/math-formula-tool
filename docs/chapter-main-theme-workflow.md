# 章節主題整理流程

這份流程是給「一個章節要完整整理到可上線」時使用。

## 目標結構

每一章整理完之後，應該是這個順序：

1. `章節代碼`
2. `主題`
3. `可修改版`
4. `原稿版 PDF`
5. `分支`
6. `章節大綱`
7. `下一層提醒`

## 每章要做的事

### 1. 先定主題

- 以 Word / PDF 的主題為主軸，不先從舊分支倒推。
- 主題名稱不要帶 `主題1：`、`主要主題1：` 這種前綴。
- 主題名稱要能直接拿去做：
  - 主題頁標題
  - 章節大綱第一欄
  - PDF 檔名對照

### 2. 建立主題頁

- 在 `formula-db.json` 裡面把主題掛在章節 root 下面。
- 主題 id 固定成 `chapter-code + main-theme + slug`。
- 舊資料先不要大拆，先往主題下面掛。

### 3. 補主題的可修改版

- 來源以主題整理表為主。
- 優先整理成 `重點 / 整理` 兩欄表格。
- 數學符號要改成主頁能直接顯示的 TeX。

例如：

- `√a` -> `\\(\\sqrt{a}\\)`
- `a/b` -> `\\(\\frac{a}{b}\\)`
- `a<b` -> `\\(a<b\\)`

### 4. 掛主題的原稿版

- 每個主題要對應一個 PDF。
- PDF 檔放在 `data/main-theme-overviews`
- 命名規則：
  - `{chapter-code}-topic-{index}-{slug}.pdf`

### 5. 掛分支

- 先把原本舊主題掛到新主題下面。
- 原本舊分支再保留在下一層。
- 這一步先求穩，不急著一次重寫內容。

### 6. 由主題反推章節大綱

- 章節大綱第一欄：直接用主題名稱。
- 第二欄：統一先寫 `主題`。
- 第三欄：優先取主題整理表中的重點欄，不先取舊分支名稱。

也就是：

- `下一層提醒 = 主題整理表的重點`
- `分支 = 後續逐步從這些重點拆出來`

### 7. 再從重點拆分支

- 章節大綱第三欄出現的重點，後續要逐步變成真正的分支。
- 這一步是後續深化，不一定第一次就全部做完。

例如：

- `指數律`
  - 同底數乘除
  - 冪的冪與積的冪
  - 零次方與負指數
  - 分數指數

## 驗收順序

每章驗收時照這個順序看：

1. 主頁章節卡有沒有先顯示主題
2. 主題頁有沒有 `可修改版 / 原稿版`
3. 章節大綱有沒有用新主題名稱
4. 章節大綱第三欄有沒有改成主題重點
5. 舊資料有沒有穩定掛在主題下面

## 現階段建議

目前先用這個節奏：

1. 先完成主題
2. 先完成可修改版與原稿版
3. 先完成章節大綱
4. 再逐步把重點拆成真正分支

這樣速度最快，也最不容易亂掉。
