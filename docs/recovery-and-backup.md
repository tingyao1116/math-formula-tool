# 資料恢復與備份

## 這次為什麼會出問題

這次資料大量消失的核心原因不是單一公式寫錯，而是：

1. `formulas.js` 同時承擔了「內容資料」與部分初始化入口。
2. `formula-data.js` 又同時負責「章節結構、章碼、排序、主題掛載」。
3. 管理頁修改後的內容只存在瀏覽器 `localStorage`。

這三件事混在一起時，只要其中一個點壞掉，就可能造成：

- 首頁無法初始化
- 管理頁顯示 0 筆
- 下拉選單空白
- 內容被 fallback 骨架取代

## 現在的暫定拆法

### 1. 內容資料

- `data/formula-content.js`
- 只放主題內容資料
- 例如：標題、公式、說明、範例、注意事項、常見錯誤、標籤、練習

### 2. 結構資料

- `formula-data.js`
- 目前先專注在：
  - 章碼
  - 年級 / 學期 / 章節排序
  - 主題與分支的掛載
  - 管理頁儲存與合併邏輯

### 3. 章節總表

- `chapter-overviews.js`
- 只放各章的：
  - 原稿版 PDF
  - 可修改版大綱

## 之後的安全工作流程

### 每次大量修改前

先執行：

- `scripts/create-project-backup.ps1`

它會把目前重要資料檔複製到：

- `backups\YYYYMMDD-HHmmss\`

### 每次管理頁有重要調整後

另外做一份：

- 管理頁 `匯出 JSON 備份`

原因：

- 瀏覽器 `localStorage` 不是穩定版本庫
- JSON 檔才是可以交給 Codex / 你自己保留的實體備份

## 建議的備份層級

### 最少要有

1. `data/formula-content.js`
2. `formula-data.js`
3. `chapter-overviews.js`
4. 管理頁匯出的 JSON

### 更穩的做法

1. 每次大改前先建立 `backups\時間戳`
2. 每次大改後再建立一次
3. 每隔一段時間把整個專案資料夾另外複製一份

## 恢復順序

如果之後再發生問題，建議照這個順序救：

1. 先看 `backups\` 有沒有最近快照
2. 再看管理頁匯出的 JSON
3. 再看 `chapter-overviews.js` 和原稿 PDF
4. 最後才用對話內容重建

## 目前狀態

- 舊內容沒有在專案內找到可直接還原的完整備份
- Edge Local Storage 也沒有直接找到可用的舊資料鍵
- 所以接下來建議：
  - 先以拆開後的架構為基底
  - 再逐章重建內容
