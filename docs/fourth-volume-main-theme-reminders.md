# 第四冊主題整理提醒

這份提醒只記第四冊目前已經踩過、之後很容易再踩一次的點。做 `s4-*` 時先看這裡，再開始動資料。

## 固定模式

1. 章節代碼是第一層，不改。
2. 章節底下先補穩定的 `主題` 層。
3. 每個主題先完成 `可修改版 / 原稿版`。
4. 舊主題與舊分支再往下掛，不要和主題層並列。
5. 章節大綱第三欄優先用主題整理裡的重點，不要直接拿舊分支名硬拼。
6. 主題標題不要帶 `主題1：` 這種前綴。

## 來源檔優先順序

1. `exports/s4-source/s4-readable-paged.pdf`
2. `高二下數A全重點_易讀版分頁版.docx`
3. 舊 `formula-db.json` 只拿來判斷既有分支，不拿來決定新主題。

## PDF 命名

- 命名規則：`{chapter-code}-topic-{index}-{slug}.pdf`
- 存放位置：`exports/main-theme-overviews`
- 第四冊對照表：`exports/main-theme-overviews/fourth-volume-topic-pdfs.json`

## 可修改版注意

- 中文一律保留 UTF-8。
- 分數、平方根、上下標一律改成明確 TeX：
  - `√(a^2+b^2+c^2)` -> `\(\sqrt{a^2+b^2+c^2}\)`
  - `A×B` -> `\(A\times B\)`
  - `cos^2α+cos^2β+cos^2γ=1` -> `\(\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1\)`
- GUI 和主頁現在都只認明確 TeX，不要期待自動轉公式。
