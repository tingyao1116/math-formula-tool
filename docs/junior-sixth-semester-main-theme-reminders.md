# 國三下主題整理提醒

## j6-1 單元 1

- 這份 `md` 的單元 1 主軸比舊章節碼更清楚，先照來源主題整理，不要硬沿用舊的零碎 root 名稱。
- `j6-1-1` 先放基本形式、圖形與對稱軸、頂點式意義；重點是式子和圖形的基本對應。
- `j6-1-2` 放配方法、圖形平移、最大最小值與值域；這一章的核心是把一般式整理成頂點式再讀圖。
- `j6-1-3` 放與座標軸交點、二次函數和一元二次方程式的關係、判別式、已知交點求函數式、圖形判讀提醒。
- 舊資料裡 `參數 a 對圖形寬窄與方向的影響` 比較適合掛回 `二次函數的基本形式`，不要留在舊的應用章。
- `可修改版` 直接取 `國三下全重點_易讀版分頁版.md` 的原主題內容，保留原中文和 `$...$`，再轉成前端可吃的 `\\(...\\)`。
- 原稿版先依目前分頁 PDF 一主題一頁切：單元 1 依序用第 `2~12` 頁。

## j6-2 單元 2

- `j6-2-1` 目前只有一個章節碼，所以這一整段立體圖形都要掛在同一章底下，不要自行拆成多個章節。
- 來源 `md` 的十個主題順序很清楚：先辨認形體、再看視圖與展開圖、接著區分表面積與體積，最後到各種立體的體積與複合題。
- 這章沒有像前幾章那樣穩定的舊 root 可以直接重掛，所以先把 `主題層 / 可修改版 / 原稿版 / 章節大綱` 做完整，分支之後再慢慢補。
- `表面積與體積的差別` 要單獨成一個主題，不要和 `立體圖形的表面積計算` 混成同一頁。
- `角柱與圓柱的體積`、`角錐與圓錐的體積`、`球的表面積與體積` 都是不同公式群，不能為了簡化而合併。
- `可修改版` 直接取 `國三下全重點_易讀版分頁版.md` 的原主題內容，保留原中文和 `$...$`，再轉成前端可吃的 `\\(...\\)`。
- 原稿版依目前分頁 PDF 一主題一頁切：單元 2 依序用第 `14~23` 頁。
