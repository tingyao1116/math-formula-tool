# History 文件夾說明

`docs/history/` 用來放已退役、已過期、或只保留備查價值的文件。

這裡的文件原則上：

- 不再作為目前正式規則
- 不再作為目前操作流程
- 只保留歷史脈絡或追查用途

## 命名規則

歷史文件請放在日期資料夾裡：

- `docs/history/YYYY-MM-DD/`

檔名再加上時間戳：

- `YYYY-MM-DD_HH-mm-ss-original-name.md`

例如：

- `docs/history/2026-06-26/2026-06-26_15-31-50-practice-management-plan.md`

## 什麼應該放進來

- handoff
- reminder
- dated snapshot
- migration plan
- 舊版規格草案
- 已退役但想保留一份的文件

## 什麼不應該放進來

- 現在仍在使用的正式流程
- 現在仍在使用的資料結構說明
- 新人接手時第一時間要看的規則

這些應該留在 `docs/` 根層。
