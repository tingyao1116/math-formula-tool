# 全等的意義與對應關係

> 來源整理：改國二下6_三角形的全等_易讀版.md

## 全等、對應頂點、對應邊與對應角

> 學習目標：全等表示大小和形狀都一樣；寫全等式時，頂點順序會告訴你誰對應誰。

### 先抓住核心
- 兩個圖形可以完全重疊，就稱為全等。
- △ABC ≅ △DEF 的順序代表 A 對 D、B 對 E、C 對 F。
- 對應頂點決定對應邊：AB 對 DE、BC 對 EF、AC 對 DF。
- 對應角也由順序決定：∠A 對 ∠D、∠B 對 ∠E、∠C 對 ∠F。
- 全等三角形的對應邊相等、對應角相等，面積和周長也相等。

### 解題流程
1. 先看全等式的頂點順序。
2. 把第一個三角形的第 1、2、3 個頂點分別對到第二個三角形的第 1、2、3 個頂點。
3. 依頂點對應列出對應邊與對應角。
4. 最後再使用相等關係解長度或角度。

### 公式、性質與判斷
- **全等式**：△ABC ≅ △DEF。
- **對應角**：A=D, B=E, C=F。
- **對應邊**：AB=DE, BC=EF, AC=DF。

### 例題拆解
- 若 △ABC ≅ △DEF，且 BC = y+3、EF = 3y-1，則 y+3 = 3y-1。
- 若 △ABC ≅ △DEF，則 △DEF 周長可直接等於 △ABC 周長。
- 若寫成 △ABC ≅ △EFD，對應關係就會完全不同，所以順序不能亂寫。

### 易錯提醒
- 忽略全等式順序，直接用圖上的左右位置判斷對應。
- 只記得邊相等，忘了對應角也相等。

### 小練一下
- 若 △ABC ≅ △PQR，AB 對應哪一邊？
- 若 △ABC ≅ △DEF，∠C 對應哪一個角？

### 記憶鉤子
- 全等式的順序就是對應表。
- 先對應，再代數；不要看到相似字母就亂連。
