# practice-learning

這個資料夾放的是多個練習頁共用的「學習路線資料」，不是單一頁面的互動程式。

## 主要用途

- `practice-learning-architecture.js`
  - 基底能力架構
- `practice-learning-architecture-v3.js` 到 `practice-learning-architecture-v7.js`
  - 依年級 / 冊別往後補上的技能、階段、能力節點
- `practice-ability-map.js`
  - 提供能力地圖頁使用的整理後資料
- `practice-skill-tree.js`
  - 提供技能樹頁使用的整理後資料
- `practice-quest-campaign.js`
  - 提供任務闖關頁使用的關卡 / 路線資料

## 目前使用這些資料的頁面

- `ability-practice.html`
- `skill-tree-practice.html`
- `quest-practice.html`

## 整理原則

- 頁面互動程式放在各頁自己的資料夾
- 多頁共用的學習架構、能力節點、技能樹資料放在這裡
- 如果只是新增某一頁按鈕或版面，不要改這裡
- 如果要規畫新的練習線路、能力分段、前後技能關係，優先從這裡整理
