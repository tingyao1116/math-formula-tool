# 第二章：空間中的平面與直線

### 2-1 空間中的平面

#### 重點歸納

* **平面的法向量**：垂直於平面的非零向量稱為**法向量**，記為 $\vec{n} = (a, b, c)$。  
* **平面方程式的表示法**：  
* **點法式**：通過點 $P(x_0, y_0, z_0)$ 且法向量為 $(a, b, c)$ 的平面為 **$a(x-x_0) + b(y-y_0) + c(z-z_0) = 0$**。  
* **一般式**：**$ax + by + cz + d = 0$**，其中 $(a, b, c)$ 即為該平面的法向量。  
* **截距式**：若平面與三軸交於 $(a, 0, 0), (0, b, 0), (0, 0, c)$，則為 **$\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1$**（$abc \neq 0$）。  
* **兩平面的關係**：  
* **夾角**：兩平面的夾角 $\theta$ 等於其兩法向量之夾角或其補角，**$\cos \theta = \frac{|\vec{n}_1 \cdot \vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$**。  
* **平行**：兩平面平行 $\iff$ 法向量平行（$\vec{n}_1 // \vec{n}_2$）。  
* **垂直**：兩平面垂直 $\iff$ 法向量垂直（$\vec{n}_1 \cdot \vec{n}_2 = 0$）。  
* **距離公式**：  
* **點到平面距離**：點 $P(x_0, y_0, z_0)$ 到平面 $ax+by+cz+d=0$ 的距離為 **$\frac{|ax_0+by_0+cz_0+d|}{\sqrt{a^2+b^2+c^2}}$**。  
* **兩平行平面距離**：兩平面 $E_1: ax+by+cz+d_1=0$ 與 $E_2: ax+by+cz+d_2=0$ 的距離為 **$\frac{|d_1-d_2|}{\sqrt{a^2+b^2+c^2}}$**。

#### 重要題型

* **求平面方程式**：給定「三點」、「一直線與線外一點」或「兩相交直線」，利用外積求出法向量再代入點法式。  
* **垂直平分面問題**：求線段 $\overline{AB}$ 的垂直平分面（過中點且以 $\vec{AB}$ 為法向量）。  
* **投影與對稱**：求點對平面的投影點、對稱點坐標，或直線在平面上的正射影直線。  
* **體積極值問題**：利用截距式與算幾不等式，求平面與三坐標平面圍成之四面體的最小體積。

### 2-2 空間中的直線

#### 重點歸納

* **直線的方向向量**：與直線平行的非零向量 $\vec{v} = (a, b, c)$，直線上的任兩點所成向量必與 $\vec{v}$ 平行。  
* **直線方程式的表示法**：  
* **參數式**：過點 $(x_0, y_0, z_0)$ 且方向向量為 $(a, b, c)$ 的直線為 **$\\{x=x_0+at, y=y_0+bt, z=z_0+ct, t \in \mathbb{R}\\}$**。這是處理點坐標問題最常用的工具。  
* **對稱比例式**：若 $abc \neq 0$，則表示為 **$\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c}$**。  
* **兩面式**：由兩個不平行的平面交集表示，其方向向量 $\vec{v} = \vec{n}_1 \times \vec{n}_2$。  
* **直線與平面的關係**：將直線參數式代入平面方程式，若 $t$ 有唯一解則**相交於一點**；若 $t$ 無解則**平行**；若 $t$ 有無限多解則**直線在平面上**。  
* **兩直線的關係**：  
* **共平面**：相交於一點、平行、重合。  
* **不共平面**：既不平行也不相交，稱為**歪斜線**。

#### 重要題型

* **求交點與夾角**：求直線與平面的交點坐標，或求兩直線、直線與平面間的夾角（注意線面夾角需用 $\sin \theta$ 或 $90^\circ - \phi$）。  
* **距離計算**：  
* **點到直線距離**：利用參數式設垂足點 $H$，由 $\vec{PH} \cdot \vec{v} = 0$ 求得參數。  
* **歪斜線距離**：求兩歪斜線間的最短距離（公垂線段長），通常利用平行平面的點面距公式。  
* **包含關係問題**：求包含兩平行線或一線一外點的平面方程式。

### 2-3 三元一次聯立方程組

#### 重點歸納

* **克拉瑪公式（Cramer's Rule）**：利用行列式 $\delta, \delta_x, \delta_y, \delta_z$ 判定方程組的解。  
* **幾何判定與解的個數**：  
* **$\delta \neq 0$**：三平面**恰交於一點**。  
* **$\delta = 0$ 且有解（無限多組解）**：三平面**交於一直線**（三面互異或兩面重合）或**三面重合**。  
* **$\delta = 0$ 且無解**：三平面**兩兩相交於平行線**（三角架型）、**兩面平行與第三面各交一線**、或**三面互相平行**。  
* **平面簇（平面族）**：通過兩平面 $E_1=0$ 與 $E_2=0$ 交線的平面可表示為 **$E_1 + kE_2 = 0$**。

#### 重要題型

* **解的討論**：給定含未知參數的方程組，討論參數在何值時為「恰有一解」、「無解」或「無限多組解」。  
* **幾何關係判別**：不透過解方程式，僅由法向量與常數項判定三平面的空間位置關係（如：是否形成三角架、是否有平面平行）。  
* **求交線方程式**：利用聯立方程組求得兩平面或三平面交線的參數式。
